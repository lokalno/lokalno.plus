# Backup: Prom import dedup + session (2026-05-30)

## Що робить ця зміна

- **Лише додає** nullable-поля до `Listing` і **нову таблицю** `PromImportSession`.
- **Не видаляє** існуючі оголошення, замовлення, фото чи інші дані.
- Старі оголошення залишаються без `promImportKey` — dedup для них спрацює лише після повторного імпорту з Prom ID.

## Перед застосуванням на production

1. Зробіть повний backup БД у Neon (або `pg_dump`), якщо ще не зроблено.
2. Застосуйте `upgrade.sql` вручну або через `prisma db push` після оновлення `schema.prisma`.

## Відкат (rollback)

Див. `rollback.sql` — видаляє лише нові колонки/таблицю; дані в `Listing` не чіпає, крім очищення нових полів.
