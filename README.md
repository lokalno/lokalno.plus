# Локально — маркетплейс для України

Сайт для купівлі та продажу речей локально в Україні (аналог Vinted).  
Користувачі реєструються, додають оголошення з фото, фільтрують за містом.  
Адмін може змінити **назву сайту** та інші налаштування з панелі `/admin`.

## Можливості

- Реєстрація та вхід
- Додавання оголошень з фото (до 8 шт.)
- Фільтр за містом, категорією, пошук
- Профіль користувача
- Замовлення (купити → підтвердити → завершити)
- Повідомлення між покупцем і продавцем
- **Адмін-панель**: назва сайту, слоган, модерація, користувачі

## Швидкий старт (локально)

### 1. Встановіть Node.js

Завантажте та встановіть **Node.js 20 LTS** з [nodejs.org](https://nodejs.org/)  
Після встановлення перезапустіть термінал і перевірте:

```bash
node -v
npm -v
```

### 2. Встановіть залежності

```bash
cd C:\Users\Svitlana\lokalno-ua
npm install
```

### 3. Налаштуйте середовище

```bash
copy .env.example .env
```

Відкрийте `.env` і змініть `NEXTAUTH_SECRET` на довгий випадковий рядок.

### 4. Створіть базу даних

```bash
npm run db:push
npm run db:seed
```

### 5. Запустіть сайт

```bash
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000)
