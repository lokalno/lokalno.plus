# 🤖 Команда AI-агентів для проєкту «Локально»

Ці агенти — **правила Cursor** у папці `.cursor/rules/`.  
Cursor автоматично підключає їх, коли ви працюєте з відповідними файлами.

---

## Ваша команда

| Агент | Файл правил | Коли активний | Що робить |
|-------|-------------|---------------|-----------|
| **Ядро** | `00-lokalno-core` | Завжди | Контекст проєкту, стек, акаунти |
| **Frontend** 🎨 | `01-frontend-agent` | `components/`, `page.tsx` | UI, Tailwind, форми, українська |
| **Backend** ⚙️ | `02-backend-agent` | `api/`, `lib/`, `prisma/` | API, база, auth, безпека |
| **Admin** 🛡️ | `03-admin-agent` | `admin/`, скарги | Модерація, правила, скарги |
| **Feature** 🚀 | `04-feature-agent` | Весь `src/` | Швидко додати нову функцію |

---

## Як користуватися (для вас)

У чаті Cursor пишіть **конкретне завдання + якого агента залучити**:

### Приклади команд

```
Frontend-агент: зроби сторінку «Правила» з красивим дизайном
```

```
Backend-агент: додай блокування користувача (поле banned)
```

```
Admin-агент: додай сповіщення про нові скарги в адмінці
```

```
Feature-агент: додай рейтинг продавця після завершення замовлення
```

```
Додай оплату LiqPay — backend + frontend + admin
```

---

## Швидкі задачі → який агент

| Задача | Агент |
|--------|-------|
| Змінити дизайн кнопки, каталогу | Frontend |
| Нова API, зміна бази | Backend |
| Скарги, модерація, правила | Admin |
| Будь-яка нова функція з нуля | Feature (+ інші за потреби) |
| Назва сайту, слоган | Admin → settings |

---

## Паралельна робота (найшвидший режим)

Можна дати **кілька завдань одразу**:

> «1) Frontend: мобільне меню. 2) Admin: блокування юзерів. 3) Backend: API для блокування.»

Cursor розподілить роботу по правилах автоматично.

---

## Що ще прискорить розробку

1. **Завжди працюйте з папки проєкту** `lokalno-ua` відкритою в Cursor
2. **Один запит = одна фіча** (не «зроби все»)
3. **Після змін schema** — напишіть «запусти db:push»
4. **Desktop** — папка `moi sait` → `Zapustiti sayt.bat`
